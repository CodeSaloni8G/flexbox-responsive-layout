# flexbox-responsive-layout
## Description
This project demonstrates a responsive webpage layout using CSS Flexbox.
It includes a navigation bar and multiple cards aligned using flex properties.

## Live Demo
Live website: https://github.com/CodeSaloni8G/flexbox-responsive-layout

## Features
- Responsive navigation bar
- Flexible card layout
- Mobile-friendly design
- Uses flex-wrap and media queries

## Tools Used
- HTML
- CSS (Flexbox)
- VS Code
